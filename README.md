# COMP 421 - Database Design Project

Project Part 1: Database Design and Data Modelling for an international naval logistics firm.

## Overview

This project designs a database system for coordinating containerized freight shipping between cargo owners and vessel carriers. The system manages voyages, container assignments, port calls, and handles specialized cargo requirements (dangerous and standard goods).

## Key Features

- ER schema design with weak entities (Routes, Port Calls)
- Ternary relationships for cargo sending and receiving
- IS-A hierarchy for cargo specialization (Dangerous/Standard)
- Relational schema translation
- Support for multi-port voyage itineraries
